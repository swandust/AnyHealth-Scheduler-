## Changes

Availability now reports 503 if Calendar or reservation storage cannot be checked. A failed database insert cannot create a meeting. Null/array payloads and impossible dates receive 400. Mismatched legacy service-role JWT/project pairs fail before external booking writes. Raw booking payloads are no longer logged on persistence failure.
